Privacy Policy

Last updated: 2026-11-19 · This policy covers Seoul Rising for iOS through version 1.0.5.

The app has no accounts, analytics, advertising or tracking. Favorites are stored on your device. Versions 1.0.4 and 1.0.5 request a public schedule from a Cloudflare API. If you enable release reminders in version 1.0.5, the app also sends a notification token, an installation identifier and the one artist you select to our service. Cloudflare may process technical request information such as your IP address.

What the app does

The released Seoul Rising iOS app and its home screen widget download the public trends JSON file and display its K-pop ranking. By default, version 1.0.1 uses https://seoulrising.com/trends.json. The seoulrising.com domain is served by a Cloudflare Worker, which forwards that trends request to GitHub Pages at taejunoh.com. By default, version 1.0.0 requests https://taejunoh.com/seoulpulse/trends.json directly from GitHub Pages.

Version 1.0.2 adds artist search, version 1.0.3 adds device-local favorites, and version 1.0.4 adds the release schedule. Schedule-enabled versions request the public schedule snapshot as described below. The trends feed and schedule API are separate requests.

Information we ask you to provide

The app has no sign-in or account system and does not ask for your name, email, location, contacts, photos or other personal details. It contains no analytics, advertising, crash-reporting or tracking SDKs, and it does not use the advertising identifier. Apple's privacy manifest declares no tracking and no collected data types for version 1.0.3.

Data stored on your device

  • A cached copy of the most recent feed, so the app and widget can show content when you are offline.
  • Optionally, a custom feed URL, only if you enter one in Settings (intended for developers).
  • In version 1.0.3 and later builds with artist favorites, your full favorites list is stored locally on your device. If you enable release reminders in a supported build, the one artist selected for reminders is sent to our service as described below.
  • In schedule-enabled versions, a cached copy of the public schedule may be stored locally so it can be displayed when the service is unavailable.

These settings and caches stay on your device and are not uploaded by the app. Feed and schedule caches are stored in the app's shared container for the app and widget. Favorites are stored in the app's local preferences.

Network requests and server logs

By default, version 1.0.1 makes a standard HTTPS request to seoulrising.com. Cloudflare operates the Worker for that domain, and the Worker forwards the request to taejunoh.com, hosted on GitHub Pages. By default, version 1.0.0 requests the GitHub Pages URL directly. Cloudflare and GitHub may process technical information such as IP addresses and request details to provide their services; each provider's privacy policy explains its practices: Cloudflare Privacy Policy and GitHub Privacy Statement.

Schedule-enabled versions make a separate HTTPS request to https://api.seoulrising.com/v1/schedules. This request goes to a Cloudflare Worker and does not pass through the trends domain or GitHub Pages. The endpoint returns the same public schedule snapshot to all users; the app does not send your selected or favorite artists as a query. Cloudflare may process the request's IP address and technical request information to provide the service. We have not confirmed specific request logging or retention practices for this endpoint. See the Cloudflare Privacy Policy for Cloudflare's practices.

Optional release notifications

If you enable release reminders in version 1.0.5, the app sends an Apple push notification device token, an installation identifier and the one artist you select to our Cloudflare service. The service uses this information to send release, schedule-change and cancellation notifications through Apple. Your full favorites list is not sent for this feature. Turning reminders off asks the service to stop notifications; an internet connection is needed to update that setting. Once the service receives the request, it removes the device token and selected artist; a minimal record remains temporarily to prevent older requests from reactivating the setting. Notification delivery is not guaranteed. Apple and Cloudflare process information as described in their respective privacy policies.

For this service, active registrations that have not been refreshed for 365 days are removed. After a successful opt-out, the remaining installation record is scheduled for deletion after 30 days. Database backups may have a separate retention period. To request help or deletion, contact seoulrising.app@gmail.com; we may need information from the app to identify the registration.

The app also loads video thumbnail images directly from YouTube's image servers (i.ytimg.com) for the videos shown in an act's detail view. That request goes from your device to Google and is subject to Google's privacy policy.

External links

Tapping a video, headline, Wikipedia article, official schedule announcement or other link opens it in your browser or the relevant app. Those sites are independent and governed by their own privacy policies. When you visit one, that provider may receive technical information from your device; Seoul Rising does not control the provider's processing.

Third parties

Seoul Rising does not sell personal data. Cloudflare handles the version 1.0.1 trends request, the separate schedule API request in schedule-enabled versions, and optional reminder registrations in version 1.0.5. GitHub Pages hosts the trends JSON requested directly by version 1.0.0 and by the version 1.0.1 Worker. Google serves video thumbnails. The providers' privacy policies describe their handling of technical request information; this policy does not make a claim about specific server logs or retention periods.

Children

The app has no accounts or direct messaging. It does not ask users, including children, to submit personal details. Network providers may process technical request information as described above.

Not affiliated

Seoul Rising is a fan-made project. It is not affiliated with any artist, label, or outlet. Headlines are shown as published and link to their original sources.
